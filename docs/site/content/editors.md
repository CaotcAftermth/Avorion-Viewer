# Editors

An editor determines what an area displays and how you work in it. Choose the editor type from the selector in an area header. The core editor types are 3D Viewport, Outliner, Properties, Info, Preferences, Color Editor and Asset Library.

Changing an editor type changes that area, not the loaded model. Split an area first if you want to keep its current editor beside the new one.

The following chapters describe each editor's header, regions, tools and mouse or keyboard actions. Long features are subchapters; smaller controls remain subsections of the relevant page.
