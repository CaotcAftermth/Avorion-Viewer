# Choose a task

| Your task | Start here | File to keep |
|---|---|---|
| Examine a ship | Open XML, then use **Object Mode** | Original ship XML |
| Try a paint scheme | **Painting & Regions**, or **Window > Open Color Workshop** | **Save preserved XML…** download |
| Compare several ship views | **Multi-View** workspace | Saved workspace layout |
| Arrange turrets | **Armament**, **Asset Library > Turrets**, and **Select Sockets** | Original designs and separate working backups |
| Attach a reusable ship section | **Asset Library > Components** | Component pack and ship component setup JSON |
| Check aiming directions | **Properties > Weapon Coverage** | Coverage CSV or JSON, if needed |
| Demonstrate a turret firing | Open a turret asset workspace | Saved library asset and showcase export |
| Make a picture | **File > Advanced Export… > Image Export** | PNG, WebP, or JPEG |
| Make a technical sheet | **Image Export > Blueprint** | Prepared blueprint image |
| Make a rotating ship animation | **Image Export > Turntable GIF** | GIF |
| Transfer a 3D model | **File > Advanced Export…** | GLB, glTF package, or OBJ package |
| Prepare print geometry | **Advanced Export > 3D print** | Validated STL or 3MF, plus the original XML |

**Ctrl+S saves a Model Project when a model is open.** Use section 19 to choose a project, workspace profile, or game XML.

For a first project, open a ship, inspect a few blocks, paint a small selection, and download a preserved XML copy. Then make a screenshot.
