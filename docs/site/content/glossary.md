# Terms used in this guide

| Term | Meaning |
|---|---|
| Alpha | The strength or transparency part of a color value |
| Asset | A reusable design saved in a local library |
| Attachment point | The primary frame that determines how a component mounts |
| Baseline | A saved analysis result used for comparison |
| Block bounds | A rectangular extent around a block |
| Blueprint | A technical image with arranged views, dimensions, or annotations |
| Camera key | Saved camera framing at a timeline time |
| Channel | Primary or Secondary paint data |
| Coaxial assumption | Coverage or demo behavior that treats a weapon as fixed rather than freely tracking |
| Component | A reusable design that attaches to a receiving socket |
| Context | The editor, tool, or selected item that receives an action |
| Coverage | Estimated eligible aiming paths under the chosen assumptions |
| Frame | In navigation, fit an item in view; in animation, one image at one time |
| Geometry | The model's shapes and surfaces |
| Gizmo | An on-screen navigation or manipulation control |
| Instance | A mounted copy of a reusable asset |
| Library revision | A version of the saved reusable design |
| Native coordinates | Coordinates from the Avorion XML, before viewer placement |
| Orthographic | Projection in which parallel lines remain parallel |
| Overlay | Extra information drawn over the model, such as grids or guides |
| Palette | A saved or proposed set of paint colors |
| Pan | Move the view sideways or vertically |
| Perspective | Projection in which distant objects appear smaller |
| Pitch / elevation | Up-and-down rotation of a barrel or camera |
| Printable shell | Solid-geometry export that removes internal block boundaries |
| Region | A named group of blocks for the current model session |
| Scope | The set of items an operation can affect |
| Session | The current working visit to the app |
| Shading | How the app draws and lights the model's surfaces |
| Snapshot | A fixed copy of the state used to prepare an export |
| Socket | A receiving attachment position and direction |
| Source XML | The original imported Avorion design document |
| Supersampling | Rendering extra working pixels to improve the final image |
| Viewport | An editor area that shows the 3D model |
| Workspace | An arrangement of editor areas and their settings |
| Yaw | Rotation around the vertical axis |
