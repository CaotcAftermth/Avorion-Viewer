# Asset Library

Browse reusable turret and component designs. Folder-based model browsing and texture import also have dedicated file commands.

## Open this editor

Use the editor-type selector in any area header and choose **Asset Library**. Split an area first if you want to keep its current editor visible. See [Window system](../window-system/).
