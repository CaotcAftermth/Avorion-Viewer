# Color Editor

Choose verified game colors, compare harmonies, save palettes, and work with named regions. Window > Open Color Workshop opens a workspace containing this editor.

## Open this editor

Use the editor-type selector in any area header and choose **Color Editor**. Split an area first if you want to keep its current editor visible. See [Window system](../window-system/).
