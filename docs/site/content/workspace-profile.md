# Workspace Profile

A Workspace Profile (**.avprofile**) moves interface and workspace settings between browsers or machines. It is separate from the model's editable project.

## Export and import

Choose **File > Export Workspace Profile…** to download the profile. Use **Import Workspace Profile…** to apply it. A profile can be applied while a model is loaded.

## What it is for

Use profiles for editor arrangements, themes, input choices and related World/Shader settings. A profile does not replace the source XML, paint history or mounted model data kept in a Model Project. Keep project and profile files with names that make their purpose clear.

## Local layout storage

Local workspace persistence remembers arrangements in the current browser. Clearing site data can remove them. An exported profile provides a portable copy; it does not back up all browser assets or texture files.
