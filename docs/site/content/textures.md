# Textures

Textures supply game surface detail. They are optional: without them, the viewer uses plain colors and fallback surfaces. Loading textures changes appearance, not block geometry.

## Load a texture folder

Use Welcome's **Load texture folder…**, or **File > Load local texture folder…**. Choose the folder containing the game texture images, wait for loading to finish, and examine the result in an appropriate material or rendered display mode.

## Browser storage and folders

Texture originals can be retained in this browser for later visits. Folder handles and permission behavior depend on the browser. If a remembered folder cannot reconnect, use the one-time picker. Clearing site data can remove retained textures; keep your game installation and original files.

## Troubleshoot appearance

Check the current display mode, whether textures loaded successfully, and any Info warnings. A loaded texture cannot provide a detail that the source asset does not contain. Lighting and shader controls also affect the result.

## Unload and reuse

**File > Unload textures** clears the viewer's loaded texture library. It does not delete the game folder. Avoid assuming a project file includes your texture library; another browser may need a separate texture import.

## Asset rights

Use textures you are allowed to access and redistribute. This documentation's tutorial ship and examples require no imported game texture pack.
