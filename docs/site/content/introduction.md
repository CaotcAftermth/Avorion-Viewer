# Introduction

Avorion Viewer opens Avorion ship XML in your browser. Use it to inspect construction, experiment with paint, arrange attachments, analyze aiming coverage, and create images or 3D exports. It is a viewer and presentation tool, not the game's ship builder or combat simulation.

## Read this manual

**User Interface** explains the window system and shared controls. **Editors** describes each editor's header, regions, tools and settings. **Model Project**, **Workspace Profile**, **Export** and **Textures** describe the files and resources used across editors.

Menu paths use **File > Open Project…** notation. Shortcuts describe the default keymap; custom bindings and browser-reserved keys can differ. Images show specific saved examples, not a required layout. Open a figure to inspect its full-resolution capture in a modal. Click outside it, press Escape, or use Close to return to the page. Animations have explicit Play/Stop controls, and interactive illustrations are optional.

## First model

Download the [Tutorial Courier XML](../examples/tutorial-ship.xml), then follow [Open your first ship](../import/). The small model needs no game textures. Keep the original file while trying painting and export.

## Where your work lives

The app processes models locally. Browser storage helps resume sessions, but it is not a backup. Save a Model Project for editable work and use the appropriate export for a game XML, image, or mesh. A Workspace Profile carries interface settings rather than model edits.

## Example model

The Tutorial Courier is a temporary documentation fixture. It will be replaced by the user-provided ship XML when available; none of the instructional controls depend on this particular design.
