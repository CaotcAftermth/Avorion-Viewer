# Model Project

A Model Project is an editable working file with the **.avproject** extension. It keeps model-specific work rather than only a picture or mesh of the current result.

## Save and open

Use **File > Save Project…** or the default **Ctrl+S** binding. **Save Project As…** creates a named variant. Reopen it with **File > Open Project…**. Check the resulting download; browser session restoration is not a portable backup.

## Included work

Projects retain source XML and supported working edits such as paint, regions, hidden blocks and mounted copies. **Save Current Views with Project** can include viewport cameras. Texture libraries remain local to the browser rather than becoming a portable game texture pack.

## Different from game XML

**Export Avorion XML…** creates a game-oriented XML copy. It is not the same format as an editable Model Project and does not promise to retain every viewer-only arrangement. Keep both when you need editable work and a game copy.

## Revised source

Use **Replace Source XML…** to review correspondence and conflicts when updating the source of an existing project. Save a project copy before applying a replacement. The Saving & Recovery subchapter describes the other persistence routes.
