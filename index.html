QUICK START

Open a ship.
Look it over.

  1. OpenDrop an Avorion ship .xml onto the window, or use File > Import Avorion XML.
  2. TexturesDrop the game's block texture folder, or use File > Load local texture folder. They are kept in this browser.
  3. OrbitMiddle-drag orbits, Shift+middle-drag pans, the wheel zooms. Home frames the ship. No middle button or numpad? Help > Input style switches to Laptop or Trackpad controls.
  4. InspectClick a block for its details in Properties. Ship Structure groups blocks by type or material; right-click for Focus, Isolate and Hide.
  5. PaintPress Tab for Paint Mode, or open Window > Open Color Workshop. Ctrl+Z undoes a stroke.
  6. SaveFile > Save preserved XML writes your colors back into the ship file. File > Advanced Export makes GLB, OBJ, STL or 3MF.
